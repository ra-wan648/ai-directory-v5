What the first-octet bits mean

  
The least-significant bit of the first octet (I/G) distinguishes unicast (0) from multicast (1) addresses; the second-least-significant bit (U/L) distinguishes globally unique, vendor-assigned addresses (0) from locally administered ones (1). Randomly generated addresses should be locally administered so they never clash with real hardware.

  
Notation variants

  
Most systems write MACs as six colon-separated pairs (AA:BB:CC:DD:EE:FF); Windows often uses hyphens, and Cisco gear uses three dot-separated groups (aabb.ccdd.eeff). The underlying 48 bits are identical.






  
Frequently asked questions

  
Are these MAC addresses real device addresses?
No. They are cryptographically random 48-bit values intended for testing, documentation, and lab use. Never impersonate a real device's MAC address on a network you do not own.

  
What do the unicast/multicast and locally-administered toggles do?
The least-significant bit of the first octet (I/G) marks the address as unicast (0) or multicast (1); the second-least-significant bit (U/L) marks it as globally unique (0) or locally administered (1).

  
What is Cisco dot notation?
Cisco equipment writes MAC addresses as three groups of four hex digits separated by dots, e.g. aabb.ccdd.eeff, instead of six colon-separated pairs.
