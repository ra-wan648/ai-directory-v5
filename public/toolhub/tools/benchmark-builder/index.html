How to use

  1. Paste the code to measure as a function body — args is available as a variable.
  2. Provide any inputs your snippet needs as a JSON object, e.g. {"n": 1000}.
  3. Choose 1k–1M iterations and hit Run benchmark for ops/sec plus average, min, and max time per operation.

How it is measured

Your snippet runs once per iteration inside a timed loop using performance.now(). A 500-iteration warmup runs first so the JIT compiler settles, then ops/sec, average, min, and max per-operation times are reported from the real run.

Reading the numbers

Ops/sec is best for comparing two approaches; average is the typical cost; a large max usually means garbage collection or a slow first iteration slipped in. Re-run to confirm — real machines vary.

Frequently asked questions

How is the benchmark measured?

Your snippet runs once per iteration inside a timed loop using performance.now(). A short warmup phase runs first so the JIT compiler settles, then ops/sec, average, min, and max per-operation times are reported.

Is it safe to run arbitrary code here?

Your code runs only in your own browser tab via the Function constructor — nothing is sent anywhere. Only benchmark code you wrote or trust, and avoid infinite loops.

Why does the tab freeze during a run?

Timing requires the main thread, so large runs briefly block the page. The tool yields between chunks so you see progress, and you can use fewer iterations for a quicker result.

Is this Benchmark Builder free?

Yes, it is completely free, runs entirely in your browser, and requires no signup.
