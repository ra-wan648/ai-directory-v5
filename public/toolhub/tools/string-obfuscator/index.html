Obfuscation is not encryption

  
Obfuscation only hides a string from casual reading — anyone can decode it in seconds. Never use it for passwords, API keys, or other secrets; use real encryption or keep secrets on the server.

  
No eval, no execution

  
This tool never evaluates or executes your input. It only transforms characters into escape sequences and shows the result as text.






  
Frequently asked questions

  
Is string obfuscation secure?
No. Obfuscation only hides a string from casual reading — anyone can decode it. Never use it for passwords, API keys, or secrets; use real encryption or server-side storage instead.

  
Which obfuscation style should I use?
Char-code arrays and hex escapes are the most readable to decode and widely supported. Unicode escapes work in any JS string context. Base64 produces the most compact output but needs TextDecoder/atob to decode.

  
Does the tool run eval on my string?
No. The tool never evaluates or executes your input; it only transforms characters into escape sequences and displays the result as text.

  
Is this String Obfuscator free?
Yes, it is completely free, runs entirely in your browser, and requires no signup.
