How to use

  1. Paste the base32 secret from your service, or generate a fresh random one with the button.
  2. Read the current 6-digit code — it updates automatically every 30 seconds, matching what an authenticator app would show.
  3. Click Copy code to put the current OTP on your clipboard before the window expires.

How TOTP works

TOTP combines your secret with the current time (in 30-second windows) through HMAC-SHA1, then truncates the result to 6 digits. This page performs the exact RFC 6238 computation with the Web Crypto API, so codes match Google Authenticator and compatible apps.

Keep your secret safe

Anyone with your secret can generate your codes. This tool never sends it anywhere, but avoid pasting production secrets into a shared or untrusted device.

Frequently asked questions

What is TOTP?

TOTP (Time-based One-Time Password, RFC 6238) generates a 6-digit code from a shared secret and the current time in 30-second windows — the same algorithm used by authenticator apps.

Is my secret sent anywhere?

No. The secret is processed entirely in your browser with the Web Crypto API and never leaves your device.

What is the otpauth:// URI for?

It is the provisioning format authenticator apps use. It encodes the secret, account label, and issuer so you can import this TOTP setup elsewhere.

Is this OTP generator free?

Yes, it is completely free, runs entirely in your browser, and requires no signup.
