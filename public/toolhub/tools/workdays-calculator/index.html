How to use Workdays Calculator

  1. Set your weekend — Pick Saturday–Sunday, Friday–Saturday (Middle East) or Friday only (Bangladesh).
  2. Add holidays — List holidays as YYYY-MM-DD, one per line — they are excluded from the count.
  3. Calculate — Count workdays between two dates, or add N workdays to a start date.

What is Workdays Calculator?

The Workdays Calculator answers two practical questions: how many working days fall between two dates, and what date you land on after adding N workdays — respecting weekends and holidays you define.

How this math tool works

Each date in the range is checked against your weekend definition and holiday list with plain JavaScript date math. Holidays falling on weekends are ignored since those days are already excluded.

Privacy and limits

All calculations run locally in your browser — nothing is uploaded or stored. Holiday lists are per-session; paste your own each time.

Workdays Calculator — frequently asked questions

Which weekend options are supported?

Saturday–Sunday (most of the world), Friday–Saturday (many Middle East countries), Friday only (Bangladesh), Sunday only, and Thursday–Friday. Pick the one that matches your country.

How do holidays work?

Type each holiday as YYYY-MM-DD, one per line. Holidays that fall on a workday are excluded from the count; holidays on weekends are ignored since those days are already excluded.

Is the start date included when adding workdays?

No. 'Add N workdays' moves forward N workdays starting after the start date — so adding 1 workday to a Friday lands on the next workday (e.g. Monday with a Sat–Sun weekend). The count mode includes both the start and end dates.

Is my data stored anywhere?

No. All calculations run in JavaScript in your browser — nothing is uploaded or stored.
