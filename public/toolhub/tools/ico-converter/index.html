ICO Converter

Convert PNG images to multi-size .ico files.


The tool renders 16×16, 32×32 and 48×48 versions and assembles a real, byte-correct multi-size .ico file in your browser.

How to use ICO Converter

  1. Open the ICO Converter page — Open ICO Converter on AI Directory in any modern browser. Nothing to install.
  2. Upload a PNG image — Choose a square PNG — ideally at least 256×256 — which is read locally in your browser.
  3. Download the .ico file — The tool renders 16, 32 and 48px versions and assembles a valid multi-size .ico file, ready to download.

What is ICO Converter?

ICO Converter turns a PNG into a genuine multi-size .ico file — the format Windows uses for program icons and some sites still use as favicons. Instead of a single image, the file contains 16×16, 32×32 and 48×48 versions, so the OS picks the sharpest size for each context.

How the ICO file is assembled

The page writes the binary ICO structure directly in JavaScript: a 6-byte header (reserved, type, image count) followed by one 16-byte directory entry per size, each pointing at PNG-compressed image data. PNG-in-ICO is a valid, widely supported encoding, and every byte is built with a DataView so the file opens in any icon tool.

Privacy and limits

Everything runs in your browser — your PNG is never uploaded. The output is a real .ico file, not a renamed PNG, so it works wherever Windows or desktop icon files are expected.
