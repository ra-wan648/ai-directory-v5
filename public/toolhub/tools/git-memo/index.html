How to use

  1. Browse the groups — setup, daily work, branching, undo, remote — or type in the search box to filter commands.
  2. Read the one-line explanation on each card to see what the command does and when to use it.
  3. Click any card to copy the exact command to your clipboard, ready to paste into your terminal.

Learn Git in stages, not all at once

The cards are ordered the way you actually learn Git: configure it once, then the daily loop of status → add → commit, then branching when you collaborate, then the undo commands for when things go sideways, and finally remotes for sharing work. Master one group before moving to the next.

A note on placeholders

Commands shown with <angle brackets> — like git branch <name> — need you to substitute your own value. Type the brackets away and write the real name, file, or URL instead.

Frequently asked questions

Is Git Memo different from a cheat sheet?

Yes. Instead of a flat list, commands are grouped into visual cards by workflow stage (setup, daily, branching, undo, remote), each with a beginner-friendly one-line explanation, live search, and click-to-copy.

Which git commands are covered?

42 essential commands: configuration and setup, everyday add/commit/status workflows, branching and merging, undoing mistakes safely, and remote collaboration with push, pull, and tags.

Do I need Git installed to use this?

No. Git Memo is a reference you read in the browser; you only need Git installed on your own machine when you run the copied commands in your terminal.

Is Git Memo free?

Yes, it is completely free, runs entirely in your browser, and requires no signup.
