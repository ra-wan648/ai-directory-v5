How to use

  1. Enter the amount you want to convert.
  2. Pick the From and To currencies — use the swap button to reverse them.
  3. The converted amount, the exchange rate, and the inverse rate update automatically with every change.

Live rates, honest fallback

Every conversion first tries the exchangerate.host live API. If the network fails or the API is unreachable, the tool falls back to a static rate table baked into this page, clearly labeled offline rates with its date (2026-09-30). Offline values are estimates, not market rates.

Mid-market reference

Shown rates are mid-market reference rates. Banks, cards, and money changers add their own margin, so the rate you actually receive will differ slightly.

Frequently asked questions

Where do the live rates come from?

Live rates are fetched from the exchangerate.host API (free tier, no key needed). Each conversion shows its source and timestamp.

What are offline rates?

If the live API cannot be reached, the tool falls back to a static rate table baked into the page, clearly labeled with its date (2026-09-30). These are estimates, not live market rates.

Are the rates exact?

Rates are mid-market reference rates. Banks and money changers add their own margin, so the rate you actually get will differ slightly.

Is this Currency Converter free?
