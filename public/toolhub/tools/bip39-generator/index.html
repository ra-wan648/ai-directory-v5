How to use BIP39 Generator

  1. Generate a phrase — Choose 12–24 words and click Generate mnemonic. The phrase and its underlying entropy appear below — write the phrase down offline.
  2. Validate an existing phrase — Switch to the Validate tab, paste any mnemonic, and click Validate mnemonic to check word membership, word count and the checksum.
  3. Keep it secret — A valid phrase is a real key. Store it on paper or in a hardware wallet — never in email, chat or screenshots.

What is BIP39 Generator?

BIP39 Generator creates and validates mnemonic seed phrases — the 12-to-24-word backups behind Bitcoin and most crypto wallets — implemented to the actual specification, not a lookalike.

How this developer tool works

crypto.getRandomValues produces 128–256 bits of entropy; Web Crypto's SHA-256 digest supplies the checksum bits; the bit stream is split into 11-bit groups indexing the official English wordlist. Validation reverses the process.

Privacy and limits

Entropy never leaves your browser, but this is still a web page: for life-changing amounts, generate seeds on an offline hardware wallet instead.

BIP39 Generator — frequently asked questions

What is a BIP39 mnemonic?

A human-readable encoding of cryptographic entropy defined by Bitcoin Improvement Proposal 39: 12–24 words from a fixed 2048-word list, where the last bits are a SHA-256 checksum of the entropy.

Are these real, usable seed phrases?

Yes — the phrases follow the BIP39 spec exactly (proper entropy size, correct checksum bits) and import into standard wallets. Treat every generated phrase as live: anyone holding it controls the funds.

Why does it need to download a wordlist?

The 2048-word English list is fetched once from the jsDelivr CDN at runtime and cached in memory, so the page stays self-contained. Generation itself uses only local crypto.

What does the validator check?

Three things: every word exists in the official 2048-word list, the word count is a valid BIP39 length (12/15/18/21/24), and the embedded checksum matches a fresh SHA-256 of the entropy.
