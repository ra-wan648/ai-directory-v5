List Converter

Convert lists between newline, comma-separated, JSON array, numbered, bulleted, SQL IN and quoted CSV — with prefix, suffix, quote, dedupe and sort options. Live conversion, right in your browser.

How to use List Converter

  1. Paste your list — Paste your items as lines, comma-separated values or even a JSON array.
  2. Pick the target format — Choose lines, comma-separated, JSON array, numbered, bulleted, SQL IN or quoted CSV.
  3. Copy the result — Tweak prefix, suffix, quotes, dedupe and sort, then copy the converted list.

What is List Converter?

The List Converter reshapes plain lists for different jobs: spreadsheet columns into comma-separated values, values into a JSON array for code, or a column of IDs into a SQL IN (...) clause — with one click and a live preview.

How this writing tool works

Your input is parsed (lines, comma/semicolon-separated text or JSON arrays are all detected), then prefix, suffix, quoting, dedupe and sort are applied before rendering into the format you pick. All with plain JavaScript in your browser.

Privacy and limits

Everything happens locally in the page. Your list is never uploaded or stored.

List Converter — frequently asked questions

Which input formats are detected?

The converter smartly detects one item per line, comma/semicolon-separated values on a single line, and JSON arrays like ["a", "b"]. Empty lines and surrounding quotes are cleaned up automatically.

How does the SQL IN format work?

Items are wrapped as ('a', 'b', 'c') with single quotes, and any single quote inside an item is doubled ('escaped'), which is the standard SQL way to quote string literals.

What do dedupe and sort do?

Dedupe removes repeated items (case-insensitively, keeping the first occurrence). Sort orders the items A to Z or Z to A. Both apply before the format is rendered, and the item count updates live.

Does my list leave my browser?

No. Conversion runs entirely in JavaScript on this page — your list is never uploaded or stored.
