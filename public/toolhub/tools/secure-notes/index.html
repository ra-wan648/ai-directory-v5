    How the encryption works
    
  
    Your password never leaves the page. It is stretched into a 256-bit key with PBKDF2 (100,000 iterations of SHA-256 and a fresh 16-byte random salt per note), then the text is sealed with AES-GCM using a random 12-byte IV. The salt, IV, and ciphertext are stored together — everything an attacker would need except your password — and the GCM authentication tag makes tampering or wrong passwords fail loudly.
    
  
    Security notes
    
  
    Notes live only in this browser's localStorage, so anyone with access to your unlocked device or browser profile could copy the encrypted vault — a weak password would then be the only barrier. Use a long, unique password, and remember: a forgotten password means a permanently unreadable note.
    

    


    
  
    Frequently asked questions
    
  
    How secure is the encryption?
    Notes are encrypted with AES-256-GCM using a key derived from your password via PBKDF2 with 100,000 iterations of SHA-256. Each note gets a fresh random salt and IV. Decryption with the wrong password fails because the authentication tag does not verify.
    
  
    Where are my notes stored?
    Only in your browser's localStorage on this device, in encrypted form. Nothing is ever sent to a server — there is no account and no cloud copy.
    
  
    What happens if I forget my password?
    The note cannot be recovered. There is no backdoor and no reset option — that is exactly what makes the encryption trustworthy, so use a password you will remember.
    
  
    Is this Secure Notes tool free?
    Yes, it is completely free, runs entirely in your browser, and requires no signup.
