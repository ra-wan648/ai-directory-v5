HMAC Generator

Compute real HMAC message-authentication codes with the Web Crypto API — perfect for API signatures and webhook verification. The signature updates live as you type; nothing leaves your browser.





HMAC-SHA-1 is shown for legacy compatibility only \u2014 prefer SHA-256 or SHA-512 for new systems.





How to use HMAC Generator


  1. Type the message and the secret key — Enter the payload to sign and the shared secret both sides know. The key field is masked; use Show key to reveal it.
  2. Pick the algorithm and output encoding — Choose HMAC-SHA-256 (the standard for webhooks and API signatures) and whether you want hex, base64 or URL-safe base64 output.
  3. Copy the live signature — The signature recomputes instantly as you type. Hit Copy signature and compare it with the signature your server computes.




What is HMAC Generator?
HMAC Generator computes Hash-based Message Authentication Codes — keyed hashes that simultaneously verify integrity and authenticity — using the algorithms behind modern API security.
How this developer tool works
Your key is imported with crypto.subtle.importKey and the signature is produced by crypto.subtle.sign with the HMAC algorithm you select, then encoded to hex, base64 or base64url in JavaScript.
Privacy and limits
Everything runs locally via the Web Crypto API; no data is transmitted. Web Crypto requires a secure context (HTTPS or localhost), which this page satisfies.




HMAC Generator — frequently asked questions


What is HMAC used for?
HMAC proves a message came from someone holding the secret key and that it was not tampered with. Typical uses: signing API requests, verifying webhook payloads (Stripe, GitHub), and session tokens.
Which hash algorithm should I choose?
HMAC-SHA-256 is the standard choice and is considered secure. HMAC-SHA-512 gives a larger security margin; HMAC-SHA-1 should only be used to interoperate with legacy systems.
Is my secret key sent to a server?
No. The signature is computed with your browser's built-in Web Crypto API (crypto.subtle). The key and message never leave this page.
What is the difference between hex, base64 and base64url output?
They are three text encodings of the exact same signature bytes. Hex is the most readable, base64 is the most compact, and base64url is safe to embed directly in URLs and filenames.
