What is TOML?

  
TOML (Tom's Obvious Minimal Language) is a configuration file format designed to be easy to read while mapping cleanly to a hash table. It powers Cargo (Rust), Python's pyproject.toml, and many other tools.

  
Dates, tables, and arrays

  
TOML datetimes become ISO 8601 strings in both outputs. Nested tables become nested objects, and arrays of tables become arrays of objects — so nothing is lost in translation.






  
Frequently asked questions

  
What is TOML?
TOML (Tom's Obvious Minimal Language) is a configuration file format designed to be easy to read, mapping cleanly to a hash table. It is used by Cargo (Rust), Python's pyproject.toml, and many other tools.

  
How are TOML dates converted?
TOML datetimes become ISO 8601 strings in both JSON and YAML output, e.g. 1815-12-10T00:00:00.000Z.

  
What happens if my TOML is invalid?
The converter shows the exact parser error with line and column numbers plus a code snippet pointing at the problem, so you can fix it quickly.
