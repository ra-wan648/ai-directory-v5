What is XML Sitemap Generator?

This tool turns a plain list of page URLs into a standards-compliant sitemap.xml file that search engines use to discover and crawl your site's pages.

How this SEO tool works

Each line is validated as an http(s) URL, duplicates are removed, and the XML is assembled with your chosen changefreq, priority and lastmod values — all in JavaScript on this page. The download is generated as a file blob, never touching a server.

Privacy and limits

Everything runs locally; your URL list never leaves the browser. The sitemap protocol allows up to 50,000 URLs per file — for very large sites, split your list across multiple files.

XML Sitemap Generator — frequently asked questions

What is a sitemap.xml file?

A sitemap.xml lists the pages of your website so search engines like Google can discover and crawl them efficiently. Submitting it in Google Search Console helps new and updated pages get indexed faster.

Do changefreq and priority affect rankings?

No, they do not affect rankings. They are hints: changefreq suggests how often a page changes and priority suggests relative importance within your site. Google treats both as suggestions only.

How do I use the downloaded sitemap?

Upload sitemap.xml to your website's root (e.g. https://example.com/sitemap.xml) and submit that URL in Google Search Console under Sitemaps. You can also reference it from your robots.txt file.

Is there a URL limit?

The sitemap protocol allows up to 50,000 URLs or 50 MB per file. This tool validates each URL you paste and works comfortably with thousands of lines; for very large sites, split the list into multiple sitemap files.
