How to use URL Parser

  1. Paste the URL and parse it — Drop any absolute URL into the input and hit Parse URL — every component appears in the breakdown table.
  2. Edit the query parameters — Change any parameter value inline, remove rows, or add new ones with + Add parameter.
  3. Rebuild the URL — Tweak protocol, host, port, path or any other component, then click Rebuild URL to get a clean, correctly-encoded URL back.

What is URL Parser?

URL Parser dissects any URL into its RFC 3986 components and lets you edit them — ideal for debugging API calls, OAuth redirects, tracking links and share URLs.

How this developer tool works

It uses the native URL and URLSearchParams APIs: components are read from a URL object, parameters render as editable rows, and Rebuild writes your edits back through the same API so encoding stays correct.

Privacy and limits

Fully local processing. URLs with credentials are shown as typed — be careful pasting secrets, and prefer the rebuilt output which keeps them intact.

URL Parser — frequently asked questions

What parts of a URL does it show?

Protocol, username, password, hostname, port, pathname, raw query string, hash fragment and origin — plus each query parameter as an editable row.

Can I edit query parameters and rebuild the URL?

Yes. Edit values directly in the parameter table, adjust the components, then hit Rebuild URL. Encoding (percent-escapes) is handled automatically.

Why does my URL fail to parse?

The parser needs an absolute URL with a scheme, e.g. https://example.com/path. Bare domains like example.com are rejected — add https:// in front.

Is my URL uploaded anywhere?

No. Parsing uses the browser's native URL API entirely on this page; the URL never leaves your device.
