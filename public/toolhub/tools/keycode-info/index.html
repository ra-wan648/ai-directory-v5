How to use

  1. Click the capture pad so it has keyboard focus.
  2. Press any key — letters, function keys, arrows, or keys with modifiers held down.
  3. Read the key, code, keyCode, location, and active modifiers; each press is added to the history table.

key vs code vs keyCode

key is the character produced ("a" vs "A" depending on Shift); code is the physical key ("KeyA") regardless of keyboard layout; keyCode is the legacy numeric code. Prefer key and code in new code.

Key locations

Location tells you which physical key fired: standard, left, right, or numpad — handy for distinguishing the two Shift, Ctrl, Alt, and Enter keys.

Frequently asked questions

What is the difference between key, code, and keyCode?

key is the character produced (e.g. "a" or "A" depending on Shift); code is the physical key (e.g. "KeyA") regardless of layout; keyCode is the legacy numeric code for the key.

What does key location mean?

Location tells you which physical key fired: standard, left (e.g. left Shift), right (e.g. right Ctrl), or numpad — useful for distinguishing the two Shift, Ctrl, Alt, and Enter keys.

Why don't some keys register?

The browser or OS may intercept certain keys (like F12 or OS shortcuts) before the page sees them. The pad also blocks Tab and Space from moving focus so they can be measured.
