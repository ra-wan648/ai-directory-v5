How to use

  1. Hit Generate new prefix to draw a fresh 40-bit random global ID from the Web Crypto API and build an fd00::/8 /48 prefix.
  2. Copy the /48 site prefix (e.g. fd12:3456:789a::/48) for your site or lab.
  3. Copy any of the suggested /64 subnets for your VLANs, labs, or router advertisements.

What is a ULA?

A Unique Local Address (RFC 4193) is IPv6's equivalent of private IPv4 space such as 10.0.0.0/8. ULAs live in fd00::/8, are never routable on the public internet, and are meant for private networks, labs, and VPNs.

Why the global ID must be random

RFC 4193 requires the 40-bit global ID to be pseudo-random so that two independently generated prefixes are overwhelmingly unlikely to collide — that is what makes them "unique" when companies merge networks or connect VPNs. This tool draws those 40 bits from crypto.getRandomValues().

What is the difference between a /48 and a /64?

The /48 is your site prefix (16 bits of subnet space follow it). Each /64 is a single link/subnet carved out of that /48 — the standard subnet size for one network segment in IPv6.
