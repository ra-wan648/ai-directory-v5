HTML to PDF

Paste HTML, see a live preview, and print it to PDF straight from your browser. Nothing is uploaded — the whole conversion happens on your device.

How to use

  1. Paste or type your HTML into the editor above — the live preview updates as you type.
  2. Review the rendered document in the preview pane (scripts are disabled for safety).
  3. Click Print / Save as PDF, then choose Save as PDF (or Microsoft Print to PDF) as the destination in the print dialog.

What gets printed

Only the rendered document is sent to the print dialog — the editor, buttons, and page chrome are hidden automatically by a print stylesheet. Use the dialog's More settings to adjust paper size, margins, scale, background graphics, and headers/footers.

Fully private

Your HTML is never uploaded to any server. Rendering and PDF creation both run locally in your browser, so you can use this for invoices, reports, and other sensitive documents.

Frequently asked questions

Is my HTML uploaded anywhere?

No. Your HTML never leaves your device — the preview and the print output are produced entirely in your browser.

How do I save as PDF instead of printing on paper?

Click Print / Save as PDF, then pick Save as PDF (Chrome/Edge) or Microsoft Print to PDF (Windows) as the printer destination in the dialog.

Can I control page size and margins?

Yes. In the print dialog, open More settings to change paper size, margins, scale, and whether background graphics and headers/footers are included.

Do scripts in my HTML run?

No. The live preview runs inside a sandboxed iframe with scripting disabled, so embedded scripts are inert for safety.
