How to use TOTP Authenticator

  1. Add an account — Paste the base32 secret from your service (spaces are fine), give it a label, and press Add account.
  2. Read live codes — Each account shows its current 6-digit code with a 30-second countdown ring. Click a code to copy it.
  3. Verify a code — Switch to the Verify tab, enter a secret and a 6-digit code, and get an instant valid/invalid verdict.

What is TOTP Authenticator?

TOTP Authenticator generates the 6-digit rotating codes used by two-factor authentication, exactly as defined in RFC 6238: HMAC-SHA1 over a 30-second counter, then dynamic truncation to 6 digits.

How this developer tool works

The crypto pipeline is hand-written — a manual base32 decoder plus HMAC-SHA1 through the Web Crypto API, no libraries. A timer refreshes every code at each 30-second boundary, and the verify tab checks the current period plus one on either side for clock drift. Accounts persist in localStorage.

Privacy and limits

Secrets never leave your browser, but they are stored in plain text in localStorage — anyone with access to this browser profile can read them. Keep this for testing and low-stakes use; prefer a dedicated authenticator app for critical accounts.

TOTP Authenticator — frequently asked questions

What is TOTP and how does this tool generate codes?

TOTP (RFC 6238) derives a 6-digit code from your secret and the current time: HMAC-SHA1(secret, 30-second counter), then dynamic truncation. This page implements that pipeline by hand — base32 decoding and HMAC-SHA1 via WebCrypto — with no libraries.

Are my secrets uploaded anywhere?

No. Secrets are stored only in this browser's localStorage and codes are computed locally. They never touch a server. Anyone with access to this browser profile could read them, so treat saved secrets like passwords.

Why does verification allow a small time window?

Real-world clocks drift. The verifier accepts the current 30-second period plus one period before and after (±30 s), which matches what most services do.

My secret has spaces or lowercase letters — will it work?

Yes. Spaces are stripped, letters are uppercased, and padding is optional before decoding, so pasted secrets work as-is.
