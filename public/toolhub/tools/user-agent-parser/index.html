  3. Read the breakdown — The parser reports browser + version, operating system, device type (mobile / tablet / desktop) and rendering engine.

What is User Agent Parser?

User Agent Parser decodes the cryptic UA header into plain facts: which browser and version, which OS, whether it is a phone, tablet or desktop, and which rendering engine it uses.

How this developer tool works

A hand-written ~60-line regex engine tests the string against ordered patterns for Edge, Opera, Samsung Internet, Chrome, Firefox and Safari, then derives the engine (Blink/WebKit/Gecko), OS and device class from the remaining tokens.

Privacy and limits

Parsing is local; nothing is uploaded. UA strings can be spoofed, so treat results as hints, not proof — never gate security decisions on them alone.

User Agent Parser — frequently asked questions

What is a user-agent string?

A text header every browser sends identifying itself, e.g. Mozilla/5.0 (Windows NT 10.0; …). Servers use it for analytics, feature detection and bot filtering.

How accurate is the parsing?

The built-in regex engine covers Chrome, Edge, Firefox, Safari, Opera, Samsung Internet, mobile browsers, tablets and common bots. Exotic or spoofed strings may parse partially — the raw string is always shown for inspection.

What does “Use my UA” do?

It reads navigator.userAgent from your current browser and pastes it into the input, so you can see exactly what websites learn about your setup.

Can it detect bots and crawlers?

Yes — strings containing bot, crawler, spider or similar markers are flagged as Bot with the crawler name extracted when possible.
