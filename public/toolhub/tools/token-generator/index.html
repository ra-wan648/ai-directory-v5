What "cryptographically secure" means

  
Tokens are drawn from crypto.getRandomValues(), the browser's cryptographically secure random number generator — not Math.random(), which is predictable and must never be used for secrets.

  
Picking a size

  
128 bits of entropy (16 random bytes) is the standard minimum for secrets. The slider maxes out at 128 bytes (1024 bits) for keys that need extra margin.






  
Frequently asked questions

  
Are the generated tokens cryptographically secure?
Yes. All randomness comes from the Web Crypto API (crypto.getRandomValues), which is suitable for generating API keys, session tokens, and secrets.

  
What does the entropy value mean?
Entropy, measured in bits, describes how hard a token is to guess. A 128-bit token (e.g. 16 random bytes) is considered safe against brute-force guessing.

  
Which format should I choose?
Hex is simplest and URL-safe; base64url is the most compact URL-safe option; alphanumeric works where only letters and digits are allowed; UUIDv4 is the standard identifier format for databases.

  
Is this Token Generator free?
Yes, it is completely free, runs entirely in your browser, and requires no signup.
