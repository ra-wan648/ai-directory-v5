What is the Robots.txt Generator?
A visual editor for building a robots.txt file — the file at your domain's root that tells search-engine crawlers which pages they may or may not crawl. Add any number of user-agent rules, set a crawl delay, and declare your sitemap.

        
Common recipes
Block everything: one rule, user-agent *, Disallow /. Block one folder: user-agent *, Disallow /admin/. Allow everything with a sitemap: no rules at all, just the Sitemap line — or user-agent * with Allow /.

        
Important caveats
robots.txt is a request, not access control — malicious bots ignore it. Disallow also prevents Google from showing the page, so never Disallow pages you want indexed. Keep private content behind authentication instead.


Robots.txt Generator — frequently asked questions

        
Is the Robots.txt Generator free?
Yes — free with no signup and no limits.

        
Where do I put the robots.txt file?
Upload it to the root of your domain (for example https://example.com/robots.txt). Rules only apply to the host the file lives on.

        
Does Disallow keep a page out of Google?
Disallow tells crawlers not to fetch the page, which usually keeps it out of the index. But it is not a security measure — use passwords or noindex for truly private content.

        
What is crawl-delay?
An optional hint asking polite crawlers to wait a number of seconds between requests. Google ignores it (use Search Console's crawl settings instead), but some other crawlers honor it.
