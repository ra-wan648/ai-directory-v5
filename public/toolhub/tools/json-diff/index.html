    How to use

    1. Paste your original JSON document into the left textarea.
    2. Paste the modified JSON document into the right textarea.
    3. Click Compare to see added, removed, and changed values with their JSON paths, color coded for clarity.

    How differences are reported

    Both documents are parsed and walked recursively. Each difference is shown with its JSON path (for example, $.users[0].email), the kind of change, and the old and new values for changed items.

    Arrays and nested objects

    Arrays are compared index by index, and objects are compared key by key at any depth. A value that changed type (for example, an object becoming a string) is reported as a changed value.

    Frequently asked questions

    How does the JSON Diff tool detect differences?

    It parses both documents and recursively walks them, comparing keys, array items, and values. Differences are reported with JSON paths like $.user.address.city so you can locate each change.

    What do the colors mean in the diff output?

    Green rows are values added in the second document, red rows were removed from the first, and amber rows changed value between the two.

    What happens if my JSON is invalid?

    The tool validates each document before comparing and shows the exact parse error (with the browser's error message) so you can fix it.

    Is this JSON Diff free and private?

    Yes — it is free, requires no signup, and all comparison happens locally in your browser. Your JSON never leaves your device.
