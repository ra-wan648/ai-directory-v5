What is Device Info?

Device Info is a one-page diagnostic: it queries the same browser APIs websites use (navigator, screen, WebGL, Battery Status) and shows you exactly what this device reveals.

How this developer tool works

Values are collected with standard, read-only APIs — no fingerprinting tricks, no network calls. The GPU name comes from the WebGL debug-renderer extension; the battery reading comes from the Battery Status API where the browser supports it.

Privacy and limits

Everything stays on this page — nothing is uploaded or logged. Fields your browser hides for privacy (or doesn't implement) are honestly marked “Not exposed” instead of guessed.

Device Info — frequently asked questions

What information does Device Info show?

Your user agent, platform, language, screen and viewport size, pixel ratio, CPU cores, device memory (when exposed), GPU renderer via WebGL, battery level and charging state, online status, timezone and touch support.

Is this information sent to a server?

No. Every value is read locally with standard browser APIs (navigator, screen, WebGL) and rendered on the page. Nothing is uploaded, logged or shared.

Why do some fields say “Not exposed”?

Some APIs — like device memory or battery — are only available in certain browsers (mostly Chromium) or require a secure context. Firefox and Safari intentionally hide several hardware details for privacy.

Can I copy the full report?

Yes — the “Copy all as JSON” button puts the entire report on your clipboard as structured JSON, ready to paste into a bug report or support ticket.
