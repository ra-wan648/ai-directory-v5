What is RSA Key Generator?

RSA Key Generator creates genuine RSA public/private key pairs and exports them in the standard PEM (SPKI + PKCS#8) and JWK formats used by OpenSSL, SSH tooling and web APIs.

How this developer tool works

It calls crypto.subtle.generateKey with RSA-OAEP/SHA-256, exports the keys with exportKey, and base64-encodes the DER bytes into PEM blocks with 64-character line wrapping — all in your browser.

Privacy and limits

Private keys never leave your device; closing the tab destroys them. RSA-OAEP keys are for encryption, not signatures. Generation needs a secure context (HTTPS), which this page provides.

RSA Key Generator — frequently asked questions

What can I use these keys for?

These are RSA-OAEP keys (SHA-256), suitable for encryption and key wrapping. If you need signing keys instead, generate RSA-PSS or ECDSA keys with a dedicated tool.

Is a 1024-bit key safe?

No. 1024-bit RSA is considered breakable by well-funded attackers and is deprecated everywhere. Use 2048-bit as the minimum for anything real; 4096-bit for long-lived or high-value keys.

Why does 4096-bit generation take so long?

Generating an RSA key means searching for two large random primes, which is computationally expensive. 4096-bit keys need roughly 8× the work of 2048-bit keys — a few seconds is normal.

Are the keys sent anywhere?

No. Key generation, export and PEM encoding all happen locally with the Web Crypto API. The private key exists only in this page's memory.
