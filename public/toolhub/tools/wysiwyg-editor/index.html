What is WYSIWYG Editor?

The WYSIWYG Editor is a lightweight rich-text editor that runs entirely in your browser: what you see is what you get, and the output is clean, portable HTML.

How this education tool works

The editor uses your browser's built-in editing engine — every toolbar button applies standard HTML formatting instantly. Copy HTML puts the raw markup on your clipboard; Download HTML wraps it in a minimal standalone page.

Privacy and limits

Your document never leaves your device — there is no save button to a server and no account. Download the HTML file to keep your work.

WYSIWYG Editor — frequently asked questions

What can I format with the WYSIWYG editor?

Bold, italic, underline, strikethrough, H1–H3 headings, bullet and numbered lists, blockquotes, links, images by URL, text color, highlight color, left/center/right/justify alignment, and clear formatting.

How do I add an image?

Place your cursor where you want the image, press the image button, and paste the image URL. The image is embedded by reference — it must be publicly reachable for others to see it.

Is my content saved anywhere?

No. Your document lives only in the page's memory and is never uploaded or stored. Download the HTML file if you want to keep it.

Is the WYSIWYG editor free?

Yes — completely free, no account and no signup. It runs entirely in your browser.
