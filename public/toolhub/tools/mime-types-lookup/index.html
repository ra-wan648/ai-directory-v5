What is a MIME type?

A MIME type (media type) such as image/png or application/json tells browsers and servers what kind of data a file contains, so it can be rendered, downloaded, or rejected correctly. Web servers send it in the Content-Type header.

Common prefixes

text/* for plain text and code, image/* for pictures, audio/* and video/* for media, font/* for web fonts, and application/* for everything from JSON and PDFs to archives and executables.
