PDF Signature Checker

Upload a PDF to find out whether it carries a real digital signature. The file is scanned locally in your browser — never uploaded anywhere.

How to use

  1. Choose a PDF file from your device — it is read locally and never uploaded.
  2. The tool scans the raw file bytes for /ByteRange and /Sig entries that mark embedded digital signatures.
  3. Read the verdict: SIGNED or NOT SIGNED, with signature count, byte ranges, and encryption status.

Detection, not validation

This tool answers one question: does the PDF contain embedded digital signatures? It does not validate the certificate chain, check expiry, or verify revocation status. For legal or compliance-grade validation, open the PDF in Adobe Reader and inspect the signature panel.

What counts as a signature

A real signature shows a /ByteRange entry with non-zero values (the signed byte ranges of the file). An entry of all zeros is only an empty signature field — a placeholder that was never signed — and is reported as NOT SIGNED.

Frequently asked questions

How does the signature check work?

The tool scans the raw PDF bytes for /ByteRange entries and /Type /Sig objects — the markers PDF readers embed when a document is digitally signed. A non-zero byte range means a real signature is present.

Does this verify the signer's certificate?

No. This tool detects that signatures exist (detection), but does not validate the certificate chain, expiry, or revocation status (trust validation). For legal validation, open the PDF in Adobe Reader and check the signature panel.

Is my PDF uploaded anywhere?

No. The file is read locally with the FileReader API and scanned entirely in your browser.

What if the PDF is encrypted or password-protected?

The tool flags encrypted PDFs — the byte scan may be incomplete and page metadata may be unavailable. Decrypt the PDF first for a full check.
