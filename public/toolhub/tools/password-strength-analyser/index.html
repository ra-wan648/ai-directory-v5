    What is Password Strength Analyser?

    The Password Strength Analyser scores a password by its information entropy — length × log₂ of the character pool — and converts that into an estimated crack time for an offline attack.

    How this utilitie tool works

    The checklist tests the six most common weaknesses: short length, single character class, missing digits or symbols, dictionary patterns and repeated characters. Scores are weighted so short passwords can never rate highly.

    Privacy and limits

    Everything runs locally in your browser: the password is analysed in page memory and discarded when you leave. A high score is no substitute for uniqueness — never reuse passwords across sites.

    Password Strength Analyser — frequently asked questions

    Is my password sent anywhere?

    No. The analysis is pure JavaScript in this page. Your password never leaves your device — it is not uploaded, stored or logged.

    How is entropy calculated?

    Entropy = password length × log₂(character pool size). A 12-character password using lowercase + digits (36 characters) has about 62 bits of entropy.

    What is the crack-time estimate based on?

    An offline attack at 10 billion guesses per second, assuming the attacker must try half the keyspace on average: 2^(entropy−1) / 10^10 seconds.

    Can a 'strong' password still be unsafe?

    Yes — if it has been leaked in a breach or you reuse it across sites. Use a unique password per site and a password manager.
