What is Scientific Calculator?

The Scientific Calculator is a full keypad calculator with trigonometric, logarithmic and power functions, a degrees/radians switch, memory keys and an expression history.

How this utilitie tool works

Every expression is parsed by a dedicated recursive-descent parser (tokeniser → unary → power → term → expression) and evaluated safely in JavaScript — raw eval is never used, so input cannot execute code.

Privacy and limits

The live display previews the result as you type and flags problems like division by zero or unbalanced parentheses. All state stays in the page; nothing is transmitted.

Scientific Calculator — frequently asked questions

Does it support degrees and radians?

Yes. The DEG/RAD button switches the angle mode for sin, cos and tan; the current mode is shown above the keypad.

How are expressions evaluated — is eval() used?

No. A hand-written recursive-descent parser tokenises and evaluates the expression, so arbitrary JavaScript can never run.

Which functions are supported?

sin, cos, tan, log (base 10), ln, sqrt, abs, x², xʸ (^), 1/x, %, π, e, parentheses and memory keys M+, MR, MC — plus a running history of results.

Does it work offline?

Yes. Once the page has loaded, every calculation runs locally with no network needed.
