How to use

  1. Type your username and password — Unicode characters are supported.
  2. The Authorization: Basic header is generated live with correct UTF-8 base64 encoding.
  3. Click Copy header and paste it into your HTTP client, curl command, or API test.

How Basic Auth works

The client joins the username and password with a colon (username:password), encodes the result as UTF-8 bytes, base64-encodes those bytes, and sends them in the Authorization header prefixed with Basic.

A note on security

Base64 is an encoding, not encryption — anyone can decode a Basic header instantly. Always use Basic Auth over HTTPS, and prefer API tokens or OAuth for sensitive integrations.

Frequently asked questions

What is HTTP Basic Auth?

HTTP Basic Authentication sends a username and password as a base64-encoded "username:password" pair in the Authorization header. It is simple but should only be used over HTTPS.

Is base64 encoding the same as encryption?

No. Base64 is just an encoding — anyone can decode it instantly. Basic Auth must always be used over HTTPS so the credentials cannot be read in transit.

Does this tool handle non-ASCII characters?

Yes. Credentials are encoded as UTF-8 bytes before base64, so usernames and passwords with Unicode characters work correctly.
