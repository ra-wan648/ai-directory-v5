═══════════════════════════
DESIGN SYSTEM
═══════════════════════════

Philosophy: Dense, fast, minimal. NOT heavy animated.
NO canvas particles, NO 3D tilt, NO typewriter effect.
Vanilla JS only. No frameworks.

CSS Variables (styles.css):
--bg:#0d0d0d; --bg-card:#141414; --bg-hover:#1a1a1a;
--border:#1f1f1f; --accent:#22c55e; --text-1:#f2f2f2;
--text-2:#888888; --text-3:#444444;
--badge-free-bg:#166534; --badge-free-text:#dcfce7;
--badge-freemium-bg:#713f12; --badge-freemium-text:#fef3c7;
--badge-paid-bg:#1e3a5f; --badge-paid-text:#dbeafe;

Font: Inter (Google Fonts). Border-radius: 6px cards, 4px badges.

ONLY these animations:
1. Navbar green dot pulse (2s infinite)
2. Card hover: bg→--bg-hover + left border 2px --accent (0.15s)
3. Modal open/close fade (0.15s)
4. Skeleton shimmer on load

JS FILES
═══════════════════════════

js/main.js:
  DOM ready: fetchStats(), fetchNewToday(), fetchTools(1)
  fetchTools(page, filters={}): GET /api/tools with all params
  renderToolCard(tool): generate card HTML, logo logic
  setupInfiniteScroll(): observe last card, load next page
  applyFilter(key, val): update active filters, reset to page 1
  setupSidebarFilters(): click handlers for categories + quick links
  setupFilterPills(): click handlers for pricing/tag/content pills
  updateURL(filters): pushState for shareable filtered URLs
  Mobile: sidebar bottom sheet toggle

js/search.js:
  let allTools = [] // preloaded
  On load: fetch /api/tools?limit=500 → store allTools
  Cmd+K / Ctrl+K → open modal
  Modal HTML: overlay + blur + input + results list
  filterTools(query): filter allTools by name+desc+category
  renderResult(tool): favicon | name | category | pricing
  Keyboard nav: ArrowUp/Down, Enter→goto tool, Esc→close
  Click outside → close

js/blog.js:
  For blog.html: tab clicks, fetch, render cards
  For post.html: fetch post, render HTML content,
    parse faq_schema, render FAQ accordion
    estimate read time: Math.ceil(wordCount/200) min
